## 2024-05-24 - Input accessibility: Focus states and invisible labels
**Learning:** Combining `focus:outline-none` with visual focus indicators is important for maintaining both design aesthetics and keyboard accessibility. Inputs that lack visible labels should still be programmatically associated with visually hidden labels (using `sr-only` class) to ensure screen reader support.
**Action:** When adding or modifying inputs, ensure they have proper programmatic label associations (e.g., matching `htmlFor` and `id`), using visually hidden labels (`sr-only`) when a placeholder is used instead of a visible label. When using `focus:outline-none` on inputs, pair it with a visible focus indicator like `focus-visible:ring-2 focus-visible:ring-gold/50` to maintain proper keyboard accessibility within the project's design system.
